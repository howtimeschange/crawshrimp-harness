# 开放市场

客户端使用现有 Supabase Auth 会话；审核页面位于统一管理后台 `https://analytics.crawshrimp.com/#market`。统计和审核使用同一页面、同一内存登录及同一管理员表，不把凭证存到 localStorage。刷新整个后台或关闭页面后需重新登录；模块切换无需登录。

## 工作流

1. 客户端「开放市场」可按名称/平台查找已上架脚本，查看作者、功能说明、脚本版本和适配抓虾版本，一键安装并直接打开。
2. 绑定邮箱的开发者先选择或拖入完整 ZIP（最多 50 MB），自动提取版本、名称、平台和说明，再补充或修改可编辑信息及图标。主进程检查归档结构、危险路径、符号链接、文件数量和解压体积，校验 manifest 必填字段与引用脚本、脚本版本一致性，并计算 SHA-256。
3. 创建只属于自己的 draft，再上传到私有 Storage，最后提交为 pending。网络结果未知时先刷新「我的发布」；已上传的 draft 可以重试提交，未上传的 draft 需要重新发布。
4. 管理员在后台下载检查完整包，通过后 approved；拒绝和下架必须填写原因，保存审核人和时间。已上架版本与 ZIP 不允许发布者直接修改或替换；新版本重新提交。
5. 用户下载时重新检查可见性、文件长度、SHA-256 和 ZIP 结构；自动安装到「我的脚本」，成功后显示「打开」。安装不执行脚本；版本不匹配时拒绝安装，保留已有本地脚本。安装记录会与实际本地版本核对，重启仍能显示已安装。

## 数据和权限

在现有项目中先应用 `../harness-analytics/migrations/001_analytics.sql`，再应用 `migrations/001_market.sql`。市场迁移 001–005 已于 2026-09-11 在线应用；004/005 的回执及验证边界见 [LIFECYCLE.md](LIFECYCLE.md)。

- `market_packages`：元数据、状态及审核记录。普通用户只能看到已上架和自己的包。
- `market-packages`：私有 Storage 桶。待审核/拒绝/下架的文件仅发布者和管理员可读。
- `harness_analytics_admins`：复用埋点后台管理员名单。客户端不能修改该表。
- `market_submit` / `market_review`：服务端检查身份与状态转换，禁止普通用户伪造审核。并发审核只有第一个成功。
- 下载使用不缓存请求和 cache nonce；上传缓存时长为 0。已下载到用户本地的副本不会因下架而被删除。

审核后台 Worker 位于 `../harness-analytics/src/market.js`，使用用户 JWT 访问 Supabase，无 service-role 凭证。发布流程不会上传邮箱、会话、工作区或其他本地文件，只上传开发者明确选择的 ZIP 和填写的说明。审核为人工检查，不等于自动恶意代码扫描。

## 验证

```sh
npm ci
npm test
cd ../../app
node --test src/marketplace.test.js src/accountAuth.test.js
```

PGlite 使用 PostgreSQL 执行迁移和 RLS，覆盖发布者/其他用户/管理员的待审、通过、下架、不可覆盖和匿名拒绝发布。后台 shell 测试在 `../harness-analytics/src/admin-shell.test.js`，覆盖一次登录后统计与审核往返。

真实流程验收需已有加密管理员登录，显式执行：

```sh
env -u ELECTRON_RUN_AS_NODE node_modules/.bin/electron scripts/market-electron-smoke.cjs --live
```

它会创建无副作用示例 ZIP，提交并短暂上架，验证另一账号下载与本地导入，然后下架保留审核记录；不执行脚本，不删除远端审计数据。

2026-09-11 验收记录：源码 Electron 已实际显示市场导航、页面及未登录状态；完整线上流程最终通过，示例 `90e4bc65-fedc-46c7-8b32-291fee30a97a` 已下架。前序用于缓存诊断和导入校验的示例也已下架，保留审计记录。线上普通账号调用管理员 Worker 返回 403。统一后台外壳已部署并通过页面切换检查；客户端改动尚未打包发布安装器。

## 评分与评论

按顺序应用 `migrations/002_ratings.sql`。每个包版本支持 1–5 星、40 字以内公开昵称及 2000 字以内可选评论；每账号每版本一条，可编辑、删除。匿名账号和包作者不能评分。列表显示平均分/评分数，评分弹窗显示星级分布、自己的评价和每页 20 条最新评论。昵称由用户填写，不公开邮箱，不声称已验证安装。

管理员在统一后台每个包的“管理评价”中查看评价（每页 50 条），填写原因隐藏/恢复；隐藏和用户删除的评价不计入平均分。用户编辑或重新发表不会解除管理员隐藏状态。

2026-09-11：002 在线事务迁移成功；PostgreSQL RLS 覆盖单账号更新、范围检查、自评/匿名拒绝、隐藏后编辑/重发仍隐藏、恢复统计。客户端及后台 17 项测试通过，Vite 构建通过。真实 Electron 管理员会话验证评分汇总与自评拒绝，并再次完成上传/审核/安装/下架；示例 `992746d3-54b1-40b2-a34a-aa6cc34e750b` 已下架。无虚构公开好评。

图标：`003_package_icons.sql` 增加可选 PNG 缩略图。发布界面接受最大 2 MB 的 PNG/JPG/WebP，本地转换为 128×128 PNG（保留比例），未选择或加载失败显示默认虾图标。图标随包审核且不可直接覆盖；市场安装收据保存缩略图，按适配器 ID 与版本匹配到“我的脚本”和详情。旧包默认值为空，继续使用虾图标。
