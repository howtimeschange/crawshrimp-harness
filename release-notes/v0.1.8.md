# 抓虾 Harness Desktop v0.1.8

发布日期：2026-08-22

`v0.1.8` 承接 `v0.1.7` 之后的 main 累积改动，重点提升 DeepSeek 官方视觉模型、浏览器控制、并行 MCP 上下文和 Windows 运行时稳定性。

## DeepSeek 官方视觉模型

- 将 DeepSeek 官方视觉桥接与浏览器控制能力并入 main，补齐模型、会话与工具调用路径。
- 加强 DeepSeek vision preflight 和开发 shell 校验，降低未配置或不可用模型在运行时才暴露的问题。
- 修复图片生成选项传递，确保智能体发起图片生成时使用正确参数。

## 并行会话与 MCP 上下文

- 支持并行抓虾 MCP contexts，避免多个智能体会话共享或串扰同一个运行上下文。
- 优化 context lease 和工具调用绑定，使跨会话浏览器、文件和任务能力更稳定。

## Windows 运行时稳定性

- 加强 Windows agent runtime 启动流程，减少运行时目录、依赖或权限状态异常导致的启动失败。
- 对 transient SQLite sidecar ACL hardening 做容错处理，避免临时文件或旁路文件权限刷新失败阻断主流程。

## 验证

- GitHub Actions `main` 与 `v0.1.8` tag 构建会分别验证测试、Windows x64 安装包、macOS 双架构安装包、自动更新 metadata 和 GitHub Release 资产。
