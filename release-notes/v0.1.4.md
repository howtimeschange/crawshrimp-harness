# 抓虾 Harness Desktop v0.1.4

发布日期：2026-08-21

`v0.1.4` 是一次 Windows 智能体启动修复版本，聚焦安装后会话页面长时间停留在“智能体启动中”和核心状态红绿抖动的问题。

## Windows 智能体会话

- 修复 Windows 发布包中 DSH Web 首屏响应较慢时，后端已经 ready 但前端拿不到可加载地址而持续显示加载页的问题。
- `/agent/runtime` 现在会区分已验证 Web 地址和候选 loopback 地址；前端可先加载候选地址，并继续由后台完成 DSH 标记校验。
- Windows 端 DSH Web 探测窗口加长，覆盖首次解压、安全软件扫描或 I/O 较慢时的启动延迟。

## 核心状态稳定性

- 核心状态灯对短暂后端探活失败做去抖处理，避免健康检查瞬时超时就让标题栏红绿闪烁。
- 真实 failed 状态仍会立即显示，避免掩盖需要人工关注的核心服务失败。

## Runtime 残留清理

- Windows 启动时补充孤儿 DSH runtime/worker 清理，减少旧实例残留进程占用端口导致的新实例启动异常。
- 清理逻辑只终止父进程已不存在的 runtime，避免误杀仍由另一个正常抓虾桌面实例托管的进程。

## 验证

- `npm --prefix app test`
- `venv/bin/python -m pytest tests -q`
- `npm --prefix app run build:win`
- `node app/scripts/validate-update-artifacts.js app/dist --version 0.1.4`
