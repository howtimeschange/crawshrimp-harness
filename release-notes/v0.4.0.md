# 抓虾 Harness Desktop v0.4.0

本次功能更新新增供应商模型管理与脚本定时任务，改进固定会话接续和官方模型视觉桥接，并采用轻量桌面安装包。

## 模型管理与视觉

- 设置页支持管理内置和自定义供应商模型：新增、改名、编辑 ID、删除、批量编辑，以及逐模型预算和推理协议配置。
- DeepSeek 和 GLM 可从上游目录发现模型，结果由用户选择导入；草稿 Key 不保存。
- 新增 GPT-6.1 Sol、GPT-6 Sol / Luna 网关模型，并统一森马海外 OpenAI 默认地址。
- DeepSeek 官方 V4 Pro 恢复同供应商 Flash 视觉桥接；官方 GLM 5.3 / 5.2 使用同供应商 Flash 或 FlashX 识图后交回原模型继续执行，保留工具调用关联。
- 新导入的官方 GLM 型号只有在上游明确拒收图片、且尚未输出文字、思考或工具活动时，才尝试一次视觉回退。国内网关、自定义同名模型和其他供应商凭据不参与官方桥接。

## 定时任务

- 普通定时任务默认复用创建它的固定会话，沿用会话当前模型、工具、工作区、浏览器上下文及权限模式；旧 scoped 任务保留原授权范围。
- 专用会话任务持续复用自己的执行会话，保留后续调整的会话设置。
- 任务中心新增脚本定时任务，可按每天或每周计划直接运行已安装 Adapter，保存运行结果和输出文件，无需每轮请求模型。
- 改善浏览器页面关闭后的恢复、会话工作区接续及执行权限清理；本轮回答结束与外部业务结果验证分别记录。

## 轻量安装包

- 默认不再内置完整 LibreOffice 原生运行时。首次需要 Office 预览、转换或原生字体资源时，按锁文件下载并校验后写入用户数据缓存；纯 Python 文档生成无需先下载 LibreOffice。
- 缓存命中且锁文件未变化时，Office 任务可离线继续使用。完整离线 Office 包可通过 `CRAWSHRIMP_BUNDLE_OFFICE=1` 构建。
- 精简打包依赖、合并重复 OCR 资源，并完善 macOS 签名时间戳重试。

## 更新方式

- macOS Apple Silicon / Intel：首次安装或手动覆盖使用 DMG，应用内更新使用 ZIP。
- Windows x64：使用安装器在原路径覆盖安装。
- 升级保留系统用户数据目录中的会话、任务、Chrome profile 和配置。
- GitHub Release 提供正式安装包及自动更新元数据。
