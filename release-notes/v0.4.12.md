# 抓虾 Harness Desktop v0.4.12

本版修复官方模型权限刷新与响应中断处理，改进会话文档版本管理和 Office 文件交付。

- 兑换或账号权益变化后，返回客户端即可刷新官方文字与生图模型，无需重新登录；活跃任务期间延后应用配置，离线时保留上次成功配置。
- 生图表单在恢复草稿、任务或更新模型目录时恢复可用模型及兼容参数，保留有效选择和历史任务的模型信息。
- 官方文字流式响应缺少完成标记时明确标记结果未知，保留原请求及计费追踪编号，可只读核对，避免自动重复提交。
- 同一文档合并展示，内容未变时复用版本；同会话相同内容共享快照存储，草稿保留最近 10 个不同内容版本，保护终稿和用户上传原件。
- 快照空间接近上限时显示用量；满额时明确提示历史副本未保存，可打开当前原文件或清理空间后重试。已清理的历史版本保留状态提示。
- Office 图标、裁切素材和逐页预览等过程图片不再混入交付文件；过期过程缓存自动清理，改善资源列表的文件名、警告与操作布局。

升级无需卸载，保留现有会话、本地文件和配置。继续使用 GitHub / 腾讯云 COS 双源下载，校验安装包签名与 SHA512。
