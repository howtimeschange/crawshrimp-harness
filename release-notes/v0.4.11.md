# 抓虾 Harness Desktop v0.4.11

本版完善国内下载加速与登录欢迎流程，升级后继续保留现有会话、本地文件和配置。

- 国内 IP 优先腾讯云 COS，海外 IP 优先 GitHub；检查或安装包下载失败时切换备用源，继续验证签名与 SHA512。
- 更新说明也跟随当前下载源读取，并绑定待下载版本，网络受限时可以从备用源查看。
- 未登录时，各入口统一进入油画欢迎页，再由用户点击登录打开 ModelJetty 授权。授权成功后保留原页面、会话和输入内容。
- 首次引导完成状态保存在本机；升级用户、重新登录、登录过期或切换账号时，不再重复出现“准备好了，开始吧”。取消或失败后可在欢迎页重试或返回。
- 正式版自动同步 COS，新版验证成功才清理旧安装包；COS 仅保留最新版，GitHub 保留历史版本。

升级无需卸载，保留现有会话、本地文件和配置。已安装原始 v0.4.10 的用户也可以通过 GitHub 更新到本版，获得双源下载能力。
