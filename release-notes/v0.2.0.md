## v0.2.0

- 新增自动化中心，支持通过智能体创建定时、循环和条件任务，补齐权限检查、状态恢复和取消处理。
- 内置 Word、PowerPoint、Excel 运行时与设计技能，支持可编辑文档生成、模板填充、公式重算、预览和逐页视觉审查。
- 统一会话文件与浏览器资源，浏览器按需启动；改善图片、Office 和 ZIP 预览，避免重复解压并及时移除已关闭页面。
- 升级 DSH 至 0.1.2-rc.1、dsh-im 至 4.11.0，默认 DeepSeek 模型迁移至 V4.1 Flash；完善首次使用引导、模型选择和 IM 权限控制。
- 内置桌面操作技能、DWS 和更新后的 CLI；macOS 设置新增应用自动化权限入口。
- 改善附件和媒体交付、长输出恢复、跨平台运行时恢复、加载状态及会话界面，修复真实客户端走查发现的问题。

发布渠道为本仓库 GitHub Release，提供 macOS Apple Silicon / Intel 和 Windows x64 安装包及自动更新元数据。
