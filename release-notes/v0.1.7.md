# 抓虾 Harness Desktop v0.1.7

发布日期：2026-08-21

`v0.1.7` 聚焦 DeepSeek Harness 集成体验、Windows 稳定性、文件权限安全和 DeepSeek 官方模型接入。这个版本包含 `v0.1.6` 之后的本地 main 累积改动，并通过 GitHub Actions 生成正式桌面安装包。

## DeepSeek Harness 与会话体验

- 默认工作区初始化改为等待 DSH baseline，就绪后用 `{ path }` 契约创建并回读 workspace/session 投影，避免 Windows 首次启动被卡在工作区选择。
- Windows 工作区选择改为抓虾 Shell 原生目录选择器桥接，避开上游 native picker 在 Electron-as-Node 下的 worker 问题。
- 会话附件拖拽支持非图片文件走抓虾附件通道，图片继续交给 DSH 原生 composer，并修复拖拽遮罩复位和中英文文案。
- 更新下载状态在标题栏和侧栏展示圆环百分比，开发模式补充模拟下载入口用于验证 UI。

## Windows 稳定性与安全

- 新增 JS/Python 原子写文件工具，降低配置、任务数据、AI 视频产物和运行时状态在 Windows 上被部分写入或并发破坏的风险。
- 新增 Windows ACL 检测与修复工具，覆盖 BALA 工作区、AI 视频目录、知识库、适配器包、数据目录和运行时路径。
- 打包、Python 依赖下载、Chrome 管理、适配器加载、任务生命周期和文件删除安全增加回归测试。
- DeepSeek Harness staging 增强 runtime boot check，验证 web-cordis 组合、Windows browse picker 依赖和发布闭包完整性。

## 模型与仓库能力

- DeepSeek 官方 API 成为优先模型路线，使用独立 `CRAWSHRIMP_DEEPSEEK_API_KEY` 与 Base URL；未配置官方 Key 时自动回退到森马网关模型。
- 官方模型列表新增 `deepseek-v4-flash-vision-exp`，并为官方 Flash/Pro 暴露 reasoning effort 选项。
- 代码仓库安装以用户明确给出的 HTTP(S) Git URL 为准，不再做 DNS 公网性拦截；仍拒绝含账号密码的 URL，并禁用 Git file transport。

## 品牌与发布元数据

- 更新应用图标并加入 Harness badge。
- 移除 DSH 内部测试提示，发布 runtime staging 会应用依赖补丁脚本。
