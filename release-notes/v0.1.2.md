# 抓虾 Harness Desktop v0.1.2

发布日期：2026-08-20

`v0.1.2` 是一次桌面体验修复版本，聚焦 DSH composer hover 标签和左侧菜单栏闪烁问题。

## Composer hover 标签

- 修复附件按钮 hover 标签在深色主题中字体发黑、难以识别的问题。
- `@` 命令按钮恢复自定义 hover 标签，但屏蔽 DSH 原生 `[role="tooltip"]` 中常驻或错位的“命令”标签。
- 保留 `aria-label`，不牺牲键盘和辅助技术可访问性。

## 左侧菜单稳定性

- 自定义菜单项不再使用入场动画，避免 DSH 原生会话列表刷新时侧栏出现短暂闪烁。
- “展开全部”不再 `replaceChildren()` 整组重建菜单，而是按菜单 id 复用已有按钮，仅追加或移除变化项。
- 菜单按钮点击时从 DOM dataset 读取当前 id，确保复用节点后仍能正确导航。
