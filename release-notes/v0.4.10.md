# 抓虾 Harness Desktop v0.4.10

本次维护更新修复桌面更新的检查与下载竞态，包含 v0.4.9 的全部功能。

- 应用恢复焦点时，后台检查会保留已发现的可用更新，避免在确认下载时误报“当前没有可下载的桌面更新”。
- 已开始下载或进入任务等待、准备安装阶段后，自动检查保留当前进度和任务保护状态。
- 下载前仍支持手动检查并发现更新版本。
- 补充竞态与状态回归，并验证更新平台、任务等待、安装协调和界面操作。

macOS 使用 ZIP/ShipIt 应用内更新；Windows x64 使用安装器就地更新。升级沿用现有用户数据目录。

本次按发布负责人要求替换 v0.4.10 安装包，加入腾讯云 COS 下载源：

- 国内 IP 优先腾讯云 COS，海外 IP 优先 GitHub；检查或下载失败时使用另一个源。
- 官网使用相同地域分流，并提供备用下载。
- 正式版校验签名包和哈希后自动同步 COS，新版验证通过才清理旧包。
- GitHub Actions 使用受限 OIDC 临时身份，不保存腾讯云长期密钥。

- 已有会话但未登录时，点击“登录 / 注册”直接打开独立网页登录页，去掉中间确认弹窗；待授权时复用原登录页，防止重复发起。
