# 抓虾 Harness Desktop v0.4.9

本次桌面更新接入 ModelJetty 统一账号与官方模型服务，新增本地长期记忆和文件产物版本快照，并改进模型、会话、媒体与预览的可靠性。

## 账号与模型

- 通过 ModelJetty 网页授权登录，查看个人账号、套餐与用量，使用账号已开放的官方文字和图片模型；自备 API Key 模型继续独立配置。
- 官方模型的可用性、上下文预算与推理档位遵循服务端目录。账号切换、退出或模型不可用时，不静默切换到其他供应商或计费来源。
- 官方文字与图片请求保留原请求编号。中断或超时后可只读核对原请求状态，结果未知时避免重复提交。
- 保留旧供应商配置供兼容和回滚使用；新 Seedance 配置要求明确选择或填写服务地址。

## 本地记忆与文件

- 新增本地长期记忆的查询、保存、纠正与删除，区分工作区、全局及历史账号范围；账号切换时复核身份，并在写入校验失败时回滚。
- 会话文件产物保存版本快照和完整性信息，避免源文件后续变化覆盖已登记的版本。
- 大文件、快照配额不足或源文件变化时显示明确原因；需要时可主动打开经过校验的当前原文件，并提示它可能继续变化。

## 桌面体验与稳定性

- 升级 DSH 至 0.2.1-rc.2，改进视觉消息、推理协议、会话接续与工具结果投影。
- 更新欢迎引导、C1 品牌图标、设置布局和湖光主题，完善模型配置、账号状态和运行时就绪反馈。
- 改进图片会话确认、任务结果归属与列表刷新，保留失败或中断任务的原请求核对入口。
- 优化长会话资源读取；图片和 PDF 隐藏时释放图片资源或文档 Worker，保留缩放与阅读位置，减少后台资源轮询。
- 修复 Windows 请求回执持久化、DSH 回执读取、内置 Bmall CLI 构建及干净检出的 Python 测试入口，更新相关生产依赖。

## 更新方式

- macOS Apple Silicon / Intel：首次安装或手动覆盖使用 DMG，应用内更新使用 ZIP。
- Windows x64：使用安装器在原路径覆盖安装。
- 升级使用已有用户数据目录，保留会话、任务、Chrome profile 和配置。
- GitHub Release 提供正式安装包和自动更新元数据；本仓库不发布 Cloudflare R2 更新镜像。
- 0.4.9 面向桌面使用，跨设备能力继续在后续版本开发。
