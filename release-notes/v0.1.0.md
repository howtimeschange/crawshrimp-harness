# 抓虾 Harness Desktop v0.1.0

首个独立仓库桌面构建版本。

## 发布范围

- macOS Apple Silicon 安装包: `crawshrimp-harness-v0.1.0-mac-arm64.dmg`
- macOS Intel 安装包: `crawshrimp-harness-v0.1.0-mac-x64.dmg`
- macOS 应用内更新 ZIP: `crawshrimp-harness-v0.1.0-mac-arm64.zip`、`crawshrimp-harness-v0.1.0-mac-x64.zip`
- Windows x64 安装包: `crawshrimp-harness-v0.1.0-win-x64.exe`

## 说明

- 本版本在 `howtimeschange/crawshrimp-harness` 独立仓库发布。
- macOS tag 构建会使用 Developer ID 签名，并完成 Apple notarization 与 stapler 校验。
- 本版本不发布到 `https://updates.crawshrimp.com/`，不刷新主项目 `desktop-latest`。
