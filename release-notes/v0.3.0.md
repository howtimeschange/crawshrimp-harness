# 抓虾 Harness Desktop v0.3.0

本次为功能级更新，新增会话文件工作区、浏览器手动交互和归档会话恢复。

## 新增与改进

- 会话文件工作区统一打开附件、文件链接和生成产物，支持持久标签、拖动排序、双栏比较和会话布局恢复。
- Office / PDF 连续逐页阅读；切换标签或收起面板时保留阅读位置，隐藏音视频时暂停播放。
- 实时浏览器支持鼠标、滚轮、键盘及输入法，可在内嵌面板和浮窗间切换；CDP 合成器推送画面，不支持时回退到截图。
- 设置页提供归档会话列表与恢复入口；改进上传、粘贴附件的保存和会话绑定，补充视频模型配置校验。
- 精简预览标题栏，并为操作按钮补充悬停说明。

## 稳定性修复

- 静态页面在短暂 CDP 故障后恢复交互，断线后的预览交接重新建立连接。
- 迟到的资源快照不再覆盖新的浏览器活动，隐藏或切换面板时释放未完成的鼠标和键盘输入。
- 目录链接保留系统打开行为，普通文件进入会话预览；异步路径检查保留会话隔离。
- 支持原生 bash 直接输出的 JSON 产物清单，统一过滤失败状态，避免登记明确失败的交付声明。
- 补齐 QA 脚本的 CI 测试收集声明及相关回归。

## 更新方式

- macOS Apple Silicon / Intel：首次安装或手动覆盖使用 DMG，应用内更新使用 ZIP。
- Windows x64：使用安装器在原路径覆盖安装。
- 升级保留系统用户数据目录中的会话、任务、Chrome profile 和配置。
- GitHub Release 提供正式安装包及自动更新元数据。
