# 抓虾 Harness Desktop v0.1.9

发布日期：2026-08-24

`v0.1.9` 承接 `v0.1.8` 之后的 main 累积改动，重点修复长流式输出恢复、AI 视频材料状态残留，并完善 LLM Provider 配置引导。

## 智能体输出稳定性

- 加强长流式输出的保护与恢复，减少后端、worker 和前端状态不同步导致的输出中断。
- 补齐流式输出恢复链路的回归覆盖，覆盖桌面启动、agent harness contract 和运行时 hardening 场景。

## LLM Provider 配置引导

- 优化缺少 Provider 配置时的引导按钮、目标弹窗和设置页跳转，使 DeepSeek、Semir 等 provider 的配置路径更明确。
- 为 Provider 行增加品牌化呈现，并简化设置页 onboarding 交互。
- 增强 LLM gateway 与配置接口的测试覆盖，降低模型配置异常在运行时才暴露的概率。

## 桌面体验与业务工作流

- 隐藏云审批相关入口，保持 Harness 桌面端能力边界更清晰。
- 修复 AI 视频工作流中旧材料恢复状态残留的问题，避免后续任务继承过期状态。
- 微调抓虾 agent 品牌头部与本地 prompt library 相关交互。

## 验证

- GitHub Actions `main` 与 `v0.1.9` tag 构建会分别验证测试、Windows x64 安装包、macOS 双架构安装包、自动更新 metadata 和 GitHub Release 资产。
