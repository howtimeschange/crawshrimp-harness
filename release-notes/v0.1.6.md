# 抓虾 Harness Desktop v0.1.6

发布日期：2026-08-21

`v0.1.6` 是一次 Windows 桌面运行时修复版本，聚焦安装后核心服务因缺少 `pywintypes` 无法启动，以及打包阶段未能提前发现平台依赖不完整的问题。

## Windows 核心服务

- Windows Python bundle 显式安装 `pywin32` 和 `colorama`，修复 MCP 初始化导入 `pywintypes` 时核心服务退出的问题。
- Python 依赖缓存会同时校验通用与 Windows 专用 requirements；依赖文件变化、`pywintypes` 包装模块、DLL 或 `.pth` 缺失时会自动重新安装。
- 原生 Windows 构建会用随包 Python 导入 `pywintypes`、MCP 和 `core.api_server`，并执行 `pip check`，避免生成安装后才暴露缺包的产物。

## 智能体运行时与浏览器

- DeepSeek Harness staging 记录目标操作系统与架构，并校验 Sharp、Koffi、Ripgrep 的 Windows x64 原生产物。
- Windows CI 不再自动跳过 staged runtime 启动检查；检查通过 Electron 公共入口补全并验证真实可执行文件，减少 `.cmd` shim、安装时序和环境参数造成的启动差异。
- GitHub Actions 使用满足 DSH 运行时约束的 Node.js 22.19，避免正式构建落在未支持的 Node 版本上。
- Agent Worker 开发态优先解析 Electron 包内真实可执行文件，Windows 浏览器发现补齐 x86、当前用户和非系统盘的 Chrome/Edge 安装路径。

## 验证

- `npm --prefix app test`
- `PYTHONPATH=. venv/bin/python -m pytest tests -v`
- `npm --prefix app run vite:build`
- GitHub Actions `windows-2022` 原生 Windows x64 安装包构建与发布产物校验

GitHub Actions 会在 `main` 和 `v0.1.6` tag 推送后分别运行测试与桌面构建；正式 tag 构建会发布 Windows x64 安装包、macOS 安装包和自动更新元数据。
