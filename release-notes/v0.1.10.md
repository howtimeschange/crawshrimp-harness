# 抓虾 Harness Desktop v0.1.10

发布日期：2026-08-30

`v0.1.10` 承接 `v0.1.9` 之后的 main 累积改动，重点把抓虾主线业务能力、IM 机器人设置面和最新 DeepDraw / Bala / Shenhui 工作流同步到 Harness 桌面端。

## 抓虾业务能力同步

- 并入脚本列表搜索、买家秀 AI 工作流、唯品会 PDC 图片持久化、TEMU SCM 水洗附件兜底和 Shenhui 标签 / 鞋包处理改进。
- 同步 Bala 视频工作流可靠性修复，保持 AI 命名召回素材默认不选，并要求相关视频源由用户手动确认。
- 补齐最新 Crawshrimp v2.5.2 功能更新，使 Harness 桌面端继续承接主抓虾业务迭代。

## IM 机器人设置面

- 集成 DSH IM 能力，并把 IM 机器人作为独立设置入口接入 Harness。
- 设置 iframe 在渠道页面准备完成后再显示，并通过来源校验的 ready handshake 降低白屏和中间页闪现。
- 保持 IM 设置 iframe 常驻挂载，避免切换设置页时重复销毁导致的状态丢失。

## 配置与回归覆盖

- 修复 LLM Provider 设置页品牌 Logo 展示，增强 DeepSeek、Semir 等模型配置的可识别性。
- 稳定 Harness fusion 回归检查，覆盖移植后的业务工作流、IM 嵌入和桌面端设置交互。
- 更新融合计划文档，记录 Harness 与主抓虾能力同步边界。

## 验证

- GitHub Actions `main` 与 `v0.1.10` tag 构建会分别验证测试、Windows x64 安装包、macOS 双架构安装包、自动更新 metadata 和 GitHub Release 资产。
