# 抓虾 Harness Desktop v0.3.1

本次为维护更新，修复实时浏览器输入和 Office 文件预览的回归。

## 修复与改进

- 后台及最小化 Chrome 页面在预览和输入前确认页面焦点模拟，解决 CDP 输入超时及后台标签缺少首帧的问题；不移动系统鼠标，也不恢复最小化窗口。
- 输入失败后清理鼠标捕获、按键、输入法和排队事件；切换标签后旧队列的迟到失败不再干扰新操作。
- PPTX、DOCX、XLSX 按文件类型进入 Office 预览，缺少预览信息时找回已有作业的页面，普通文件则后台生成预览；原文件保持不变。
- Office 标签切走时卸载图片、切回时重新加载；文件更新和路径变化使旧请求失效，并提供错误反馈与重试。

## 更新方式

- macOS Apple Silicon / Intel：首次安装或手动覆盖使用 DMG，应用内更新使用 ZIP。
- Windows x64：使用安装器在原路径覆盖安装。
- 升级保留系统用户数据目录中的会话、任务、Chrome profile 和配置。
- GitHub Release 提供正式安装包及自动更新元数据。
