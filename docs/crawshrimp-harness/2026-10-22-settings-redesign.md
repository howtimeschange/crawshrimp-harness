# v0.5.0 设置导航与套餐用量改版

## 设计依据

按用户提供的 Codex / Claude 截图，采用固定窄侧栏、分组文字、同一套 Tabler 线性图标、中性色选中态和居中内容区。
使用 Leonxlnx/taste-skill 当前 app-screen 规范，True-black flat，seed 1258796477；保留产品字体，深浅色随现有主题。设计记录位于本机 `.codex-tmp/v050/taste/`。
主要问题：我当前使用什么套餐，官方服务额度还剩多少？
仅展示接口返回的套餐、累计消费、额度、有效期；不生成不存在的历史、周限额、热力图或重置时间。不限额指 Key 未设上限，不表示账户可无限消费。

## 改动与性能依据

- 移除设置页 out-in 退场/入场串行动画（旧退场最长 160ms、入场 transform 280ms），整面板 filter blur、缩放与子元素错峰动画。
- 侧栏改固定分组，取消 max-height 展开动画，点击目标不因展开而位移。
- 搜索覆盖原有所有设置项；窄屏使用页面选择器，保留可访问标签、键盘焦点和返回入口。
- 套餐用量首次访问后保留组件，60 秒内切回复用数据；手动刷新合并在途请求，刷新失败保留上次数据。
- 账号变化立即失效并清除数据；旧账号迟到响应不落入新账号状态。
- IM 已认证 iframe 的常驻逻辑保留，未修改业务权限或计费。

这些是代码层面消除的动画等待和重绘来源；没有录制帧时间 trace，不宣称所有设备达到固定 FPS。
