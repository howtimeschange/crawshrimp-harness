## 测试规则

- 先小范围失败路径夹具，再真实 Cordis/Session，再 Web RPC/产品服务，再配置可用的真实供应商。
- 基准至少覆盖纯文本、工具续接、截图理解、长上下文/压缩四类；同题固定输入，保留每次成功/错误与模型实际身份。少量样本仅作 smoke，不宣称统计显著提效。
- 所有测试资源使用测试前缀，不发送外部消息、不发布商品、不注册真实定时任务。
- 老版本 JSONL 只复制后测试，不在原数据上原地迁移；回退切回旧依赖与独立旧数据，不能用旧数据覆盖新业务记录。
- 每个旧产品补丁记录保留/上游替代/重写及证据；禁止通过跳过 guard 或删除断言“修复”升级。
- 未通过验证的提供方和 P2 能力不得默认为可用。可恢复错误继续修复；不可访问的外部层明确记录 blocker。
