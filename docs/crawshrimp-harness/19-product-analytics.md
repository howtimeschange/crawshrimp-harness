# 产品使用统计

客户端默认开启使用统计；用户可在「设置 → 账号 → 个人账号」关闭。已主动关闭的选择在重启后保留。登录后以当前账号上报，不采集聊天正文、文件内容、路径、密钥或键盘输入内容。

## 本次实现

- 用户活跃与新增、注册转化与留存、Agent/技能/文件预览/浏览器/定时任务使用、任务成功失败取消与耗时、可获取的模型调用与 Token、版本与系统质量。
- Electron 采集可信操作，Python 运行时补充任务与模型事件；持久化队列、重试、去重、账号隔离、迟到 Token 补全、关闭清理；生产/开发/测试环境分开。
- 复用 Supabase 登录和数据库，Cloudflare 提供管理员后台。普通账号不能访问报表；上报不使用服务角色密钥。
- 后台地址：https://analytics.crawshrimp.com/ 。未登录只有独立登录页；登录后按「数据统计」「后台管理」两级菜单组织。
- 六个统计模块提供 12 个交互图表与 12 类 CSV 导出。导出包含所选环境、周期和完整明细；缺失 Token 与待观察留存不当成零。
- 设计沿用 Harness 深炭导航、浅灰数据画布、橙色强调；统计开关为独立设置卡片，标题与开关横向对齐。

## 仓库边界

`cloud/harness-analytics/` 是独立的**本地 Git 仓库**，主仓库忽略该目录，不使用 submodule，不配置 GitHub 远端。后台前端、Worker、SQL、测试、部署配置及设计评审在该仓库维护，主项目克隆不会携带它。部署与维护者可在现有本机目录查看 README。

脚本市场客户端、市场业务迁移等属于另一个任务，不包含在本次主项目统计提交中。后台当前集成的市场审核页面随独立仓库保存。

已验证账号/采集器、Python 元数据处理、Postgres 权限/去重/统计、后台菜单与导出；真实 Electron 会话打通测试环境上报和报表回读。布局在深浅主题和窄屏验证通过。后台已部署；客户端埋点和设置改动尚未发布新安装包，已安装客户端需随后续版本更新。
