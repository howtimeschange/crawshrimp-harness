## 实施结果

- 产品常驻说明从 12,600 缩到 5,101 UTF-8 字节（减少 59.5%）。权限边界、中文可见输出、网页 CDP、桌面技能、Office 验收交付、媒体幂等、数据真实性和业务 Task Instance 规则保留。
- 身份及业务示例迁到 `integrations/deepseek-harness/skills/crawshrimp-product-guide/`。技能正文仍按需读取；没有隐藏技能入口。
- 精简 `automation_create` 的重复解释与示例，保留 `values` 字段、时间/周期/Program 契约、权限范围、失败草案可纠正、本地写入与外发区分、自然触发验收规则。`image_generate`、`skill_list`、`automation_wait_next` 的模型可见描述也缩短；工具名与参数 schema 不变。
- 新增会话内 `enable_tools` 发现入口。实验领域为 browser、office、automation、media、tasks、data、repo、delegation；通用文件/命令、技能、附件及未知扩展工具保留。
- 领域激活只在本会话增加，后续请求保持已加载组；恢复读取持久请求头和匹配成功的加载记录。旧全量会话恢复不会突然收缩。任务恢复测试须使用新会话与旧会话分别验收。
- 自动化根据服务端不可变工具白名单提前展示需要的领域；只控制模型可见性，不改变工具注册、执行权限、审批或自动化守卫。
- 同次加载的多个领域若共用同份参考文档，只返回一次。

默认 `compact`：所有工具仍可见，只精简说明。实验 `CRAWSHRIMP_TOOL_CONTEXT=domains`：按领域展示。未通过实机功能与收益门禁前，不设为默认。
