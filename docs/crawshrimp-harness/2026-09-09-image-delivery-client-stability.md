# 图片生成、读取交付与客户端稳定性改动说明

日期：2026-09-09。本次整理并提交上一批验收修复之后仍保留在工作区的三类改动。

## 图片生成展示

- 从 Vue 包装组件提取共享 `ImageGenerationReact`，供图片工作台和智能体网页会话共同使用；保留加载、结果揭示、静态预览及 WebGL 不可用时的降级行为。
- 智能体生成期间展示加载效果和轮换进度文案。工具完成或运行终止时释放加载组件与定时器。
- 根据工具调用和消息锚点放置图片任务及结果，避免后续消息把图片挤到输入框附近；用户浏览历史时不强制滚动到底部。
- 图片事件携带会话和工具标识；切换会话时隔离展示，返回或重新加载时重放当前会话的任务与产物。图片直接进入消息流，避免额外的图片产物卡重复展示。
- 运行时 staging 构建共享加载效果，产品桥提供脚本资源；生成的 bundle 加入忽略规则，提交源代码与构建入口。

## 图片读取与交付

- DeepSeek 官方 Flash/Pro 的本地 `read_image` 通过配套 Vision 路由检查图片能力；其他无图片能力的模型继续拒绝读取，原有沙箱、文件和附件校验保留。
- 兼容 DSH rc.1 的 `snapshotEvents()` 会话事件接口，文件回传要求活动中的 turn。
- 网页会话返回文件时，以该会话工作目录校验路径，通过认证上下文租约发送产物事件；失败也释放租约。IM 通道继续使用自身交付路径。
- 产物身份与事件加入工具调用标识，便于图片结果关联对应任务。
- 源图片尺寸上限从 4096 调整至 8192，字节上限仍为 16 MiB；模型请求的图片规格处理保持独立。

## 客户端稳定性

- 运行时状态轮询增加在途保护，避免慢请求叠加。
- 已加载会话遇到一次状态请求失败时保留 iframe，由后续轮询恢复状态；初始连接失败仍触发恢复流程。
- 同步 MCP 工具在工作线程中执行，避免供应商等待阻塞健康检查、SSE 和其他会话；线程执行保留上下文租约信息。
- 连接/审批测试适配正式源码中的 API 连接模块与状态查询，不依赖仓库根目录的额外 JS 副本。
