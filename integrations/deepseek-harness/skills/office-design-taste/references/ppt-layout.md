# PPT 版式参考

通过 `skill_read('office-design-taste/references/ppt-layout.md')` 读取。使用 `office-ppt` 的生成、渲染与交付流程。

## 版面与字体

新建演示默认 16:9（13.333 × 7.5 英寸），四周安全边距约 0.5–0.7 英寸；已有模板保留其尺寸。内容统一左边线、标题基线和页脚位置。常规标题 28–36 pt、正文 18–24 pt、图表标签/注释 12–16 pt 作为起点；投屏信息不能依赖小字才能读懂。标题尽量一到两行。

每页表达一个可复述的要点。允许留白，不将段落硬塞进剩余空间。内容放不下时先分组、拆页或移入附录；不要不断缩小字体。用户要求保留的内容在拆分后仍须完整可查。

## 根据内容选版式

| 内容 | 建议结构 | 检查点 |
| --- | --- | --- |
| 开场 | 标题、必要背景信息、一个关键视觉 | 避免把目录和摘要全挤在封面 |
| 结论与证据 | 上方结论标题，下方主图表，侧边短解释 | 结论要有数据支撑，单位与期间明确 |
| 方案对比 | 两到三栏共用对比维度 | 同级内容对齐，不暗改比较口径 |
| 流程/路线图 | 原生形状和连接线，适量阶段 | 阅读方向清楚，连接线不穿文字 |
| 产品/案例 | 主图与说明分区 | 保持图片比例，关键主体不被裁掉 |
| 明细 | 可编辑表格或附录多页表格 | 表头可读，行数适量，数据不遗漏 |

全稿复用少量版式家族，同类信息保持一致；只有内容结构变了才换版式。普通报告不需要每页都设计成海报。

## 可编辑实现与渲染

- 用 python-pptx 原生文本框、形状、表格、图表。统一文本框内边距、段前段后和行距，为自动换行留空间；计算 `left + width`、`top + height` 不超过安全区域，并检查实际渲染。
- 文字/形状各自可编辑；matplotlib 输出作为插图时要说明图像不可逐元素编辑。不得将整页渲染图再嵌入 PPT 冒充可编辑页面。
- 数字格式、期间、单位、来源和图例清楚。柱图一般从零开始；折线图采用能如实体现变化的刻度。不要用透视、3D 或截断坐标轴夸大差异。
- 长标题、中文换行、表格末行、脚注和图表标签是重点检查区域。细线和低对比灰字在整页显示时可能消失；缩略图总览有助于看一致性，但不能代替逐页检查。
